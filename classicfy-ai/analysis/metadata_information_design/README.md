# 메타데이터 이상의 연주 정보: 중간 발표 실험 설계

**목표:** 우리가 정의한 시간 변화·공동 변화 측정치를 메타데이터만으로 읽을 때보다
연주 임베딩을 추가했을 때 더 정확하게 읽을 수 있는지, 평균·범위 이후의 지식 보강이
추가 설명력을 제공하는지 평가한다.

현재 상태는 **설계·측정치 추출·표본 점검까지 완료**다. 예측기를 학습하거나 성능 결과를 계산하지 않았다.
측정치·입력 좌표·표본·fold·비교 조건은 [protocol.json](protocol.json)에 고정했다.

이 문서는 결과를 보기 전에 고정한 설계의 기록이다. 이후 이 protocol을 변경하지 않고 실행한
[실험 결과·figure·독립 검증](../metadata_information_results/README.md)을 별도 폴더에 저장했다.

## 1. 검증할 질문과 주 비교

| 질문 | 주 비교 | 측정치 |
|---|---|---|
| 메타데이터에 연주 요약을 추가하면 정보가 늘어나는가? | M+Q+B vs M+Q | 주 측정치 둘 모두 |
| 개별 시간 지식의 보강 효과가 있는가? | M+Q+B+T vs M+Q+B | 강약 변화 편중 |
| 공동 변화 지식의 보강 효과가 있는가? | M+Q+B+T+R vs M+Q+B+T | 구간별 빠르기–강약 관계 강도 |
| 저장된 학습 표현에서도 정보를 읽을 수 있는가? | M+Q+B+CNN/BiLSTM vs M+Q+B | 주 측정치 둘 모두, 보조 측정치 |

M은 메타데이터, Q는 길이·유효 coverage, B는 기존 14D, T는 개별 시간 통계,
R은 feature 간 변화량 상관이다. 각 임베딩을 그대로 이어 붙여 예측기에 제공한다.
앞선 거리 실험의 거리값이나 조건부 57개 후보를 입력으로 사용하지 않는다.

## 2. 임베딩에 그대로 넣지 않은 측정치

정답은 기존 정규화된 원래 beat 시퀀스에서 별도로 계산한다.
현재 T는 전곡 통계이고 R은 전곡 지연 상관이다. 아래 측정치는 **짧은 구간의 통계 분포**이므로
기존 입력 좌표 자체를 다시 읽는 과제가 아니다. 입력 좌표와 관련될 수는 있으며,
그 관계를 통해 평가 작품의 측정치를 얼마나 잘 읽을 수 있는지가 실험 대상이다.

### Y1 · 강약 변화가 구간별로 얼마나 편중되는가? — 주 측정치

1. 원래 beat index 0부터 **겹치지 않는 32-beat 구간**으로 나눈다. 짧은 마지막 구간은 제외한다.
2. 각 구간의 인접 Dynamics 차이 `ΔD` 중 양 끝이 유효한 쌍만 사용한다.
3. 구간마다 `u = sqrt(mean(ΔD²))`를 계산한다.
4. 전곡의 측정치는 `CV = SD(u) / mean(u)`다. SD는 population SD다.

`u=[1,1,1,1]`이면 CV=0, `u=[0.2,0.2,1.8,1.8]`이면 CV=0.8이다.
평균 변화 크기는 같지만 일부 구간에 변화가 집중되는 정도가 다르다.
전체 변화의 크기만 커져서 값이 커지는 효과를 나누기 위해 평균으로 정규화했다.
이 측정치는 어느 구간이 먼저 오는지는 담지 않는다. 전체 구간 순서 보존을 검증하는 과제로 해석하지 않는다.

- 31개 가능한 인접 쌍 중 **25개 이상**이 유효한 구간만 사용한다.
- 유효 구간이 **3개 이상**, 평균 변화 크기가 `1e-12`보다 커야 한다.
- 평균 변화가 0이면 측정치를 0으로 채우지 않고 `zero_mean_change`로 남긴다.
- 예측·평가에는 **log1p(CV)**를 사용한다. 이 변환도 결과를 보기 전에 고정했다.

### Y2 · 구간 내부의 빠르기–강약 관계가 얼마나 강한가? — 주 측정치

1. 원래 beat index 0부터 **겹치지 않는 64-beat 구간**으로 나눈다.
2. 두 feature 모두 양 끝이 유효한 인접 쌍에서 `ΔTempo`, `ΔDynamics`를 계산한다.
3. 각 구간의 Pearson 상관 `r_j`를 계산한다.
4. 전곡의 측정치는 `mean(abs(r_j))`다.

강한 양의 관계와 강한 음의 관계가 다른 구간에 있으면 전곡 상관에서 상쇄될 수 있다.
Y2는 방향과 별도로 **지역적인 관계의 강도**를 읽는다. 값이 높다고 더 좋은 연주라는 뜻은 아니다.

- 63개 가능한 인접 쌍 중 **51개 이상**이 유효해야 한다.
- 두 변화량 중 하나가 일정하면 그 구간의 상관은 정의하지 않는다. SD `<=1e-12`를 상수 기준으로 사용한다.
- 계산 가능한 구간이 **3개 이상** 필요하다. 실제 값은 [0,1]이며 별도 변환 없이 예측한다.
- Tempo–Rubato나 페달 내부처럼 정의상 연결된 쌍 대신 **Tempo–Dynamics**를 고정했다.

### Y3 · 구간마다 관계가 얼마나 달라지는가? — 보조 측정치

Y2와 같은 구간·상관에서 `SD(r_j)`를 계산한다. 강한 동조에서 반대 관계로 바뀌는 경우 등을 구분한다.
예를 들어 `r=[1,1,1]`은 Y2=1/Y3=0, `r=[1,1,-1]`은 Y2=1/Y3≈0.943이다.
관계 강도와 관계의 변동은 별개이므로 둘을 나눴다.

Y3에서 좋은 결과가 나온다는 이유로 Y2 대신 주평가로 바꾸지 않는다.
이 측정치들은 작품 공통 흐름 제거 후의 feature에서 계산하며, 잔차 상승을 원본 crescendo로 바로 해석하지 않는다.
beat는 기존 ASAP의 beat interval index이고 시간초나 마디와 같은 단위로 취급하지 않는다.
결측 구간을 이어 붙이거나 padding을 실제 구간처럼 사용하지 않는다.

## 3. 비교 입력

| 조건 | 입력 | 목적 |
|---|---|---|
| A0 | M | 메타데이터만의 기준 |
| A1 | M+Q | 길이·coverage까지 통제한 기준 |
| B | M+Q+B14 | 기존 평균·범위의 기여 |
| C | M+Q+B14+T57 | 개별 시간 정보의 추가 기여 |
| D | M+Q+B14+T57+R119 | 공동 변화 관계의 추가 기여 |
| E-CNN | M+Q+B14+CNN128 | 고정된 CNN 표현의 정보 |
| E-BiLSTM | M+Q+B14+BiLSTM128 | 고정된 BiLSTM 표현의 정보 |

**메타데이터 M:** 작곡가, 작품 유형, 작곡가×작품 유형 조합의 one-hot.
조합을 포함해 단순한 작곡가/유형 평균만 사용하는 약한 기준에 머무르지 않는다.
어휘는 predictor의 학습 fold에서만 만들고, 새 범주는 해당 범주 블록의 unknown/0 처리로 기록한다.
연주 파일명·녹음 ID는 제외한다. 확인되지 않은 연주자·시대 라벨을 추가하지 않는다.
평가 작품은 학습 작품과 달라 작품명 ID 자체는 재사용되지 않으므로 주 예측 입력에서 제외한다.
**같은 작품 내부의 평가에서는 작품명도 고정되므로 제목 차이에 따른 효과를 제거한다.**

**통제 Q:** `log1p(원래 beat 수)`, 전체 유효 beat 비율.
측정치를 만들 때 계산 가능한 구간 수가 길이·결측의 영향을 받으므로 모든 연주 조건에 동일하게 포함한다.
정답에서 계산한 RMS/상관 구간 수는 예측 입력으로 추가하지 않는다.

**B/T/R:** 기존 feature·통계 export를 재사용한다.
T의 70좌표 중 학습 395연주에서 유효 비율 95% 이상이고 비상수인 **57좌표**를 고정했다.
R은 같은 기준으로 **119좌표 전체**가 남았다. 미지원 지속 통계 등을 결측으로 남긴다.
선택된 T/R에 결측이 하나라도 있는 연주는 모든 비교 조건에서 함께 제외한다.
중앙값이나 0을 넣어 관계가 정의된 것처럼 만들지 않는다.
유효 좌표 선택은 정답·예측 성능을 사용하지 않은 outer-train 기준의 schema 결정이며,
inner fold별 좌표 표준화는 별도로 그 fold의 학습 부분에서만 계산한다.

**학습 임베딩:** 확대 예산에서 이미 선택한 CNN64/BiLSTM64의 전곡 128D 평균+SD 벡터.
20261006/07/08의 세 seed를 모두 평가한다. 이번 정답으로 인코더를 학습하거나 checkpoint를 선택하지 않는다.
벡터 좌표는 train-only 표준화 후 예측기에 제공한다. 코사인 거리나 L2 정규화된 거리 좌표를 주 입력으로 쓰지 않는다.
E 결과만으로 신경망 학습의 효과까지 분리해 주장하지 않는다. 학습 전/PCA와의 직접 비교는 별도 질문이다.

## 4. 평가 표본과 작품 분리

기존 데이터는 55작품·570연주이고, 저장 인코더의 split은 train 395/validation 93/test 82다.
원래 split에서 6개 작품군이 겹쳐 있었다. 인코더 학습 데이터를 옮겨 새 split인 것처럼 취급하지 않는다.

- train은 기존 395연주 그대로 유지한다.
- validation에서 train과 작품군이 겹치는 26연주를 제외해 67연주·4작품을 남긴다.
- test에서 train 또는 validation과 작품군이 겹치는 15연주를 제외해 67연주·6작품을 남긴다.
- 같은 BWV의 전주곡/푸가, 이름으로 확인 가능한 소나타 악장들은 같은 작품군으로 제외한다.
- target이 정의되지 않거나 T/R 입력이 결측이면 해당 측정치에서 모든 방법이 같은 연주를 제외한다.
- 같은 작품 안에서 비교할 수 있도록 **eligible 연주가 3개 이상인 작품**만 평가한다.

실제 데이터에서 성능 계산 전에 확인한 표본은 다음과 같다.

| 측정치 | train | validation | test |
|---|---:|---:|---:|
| Y1 강약 변화 편중 | 361연주·34작품·33작품군 | 67연주·4작품 | 67연주·6작품 |
| Y2 구간별 관계 강도 | 358연주·33작품·32작품군 | 67연주·4작품 | 56연주·5작품 |
| Y3 관계 변동 | Y2와 동일 | Y2와 동일 | Y2와 동일 |

Y2/Y3는 test의 한 작품·11연주에서 필요한 3개 64-beat 구간을 확보하지 못해 제외됐다.
짧은 작품을 제외해 생기는 범위를 함께 보고하고, 결과를 본 뒤 구간 길이를 바꿔 포함하지 않는다.
측정치끼리 표본 수가 달라도 **한 측정치 안의 모든 방법은 정확히 같은 표본**을 사용한다.
기존 test는 이전 분석에서 관찰한 자료이므로 새롭게 확보한 독립 데이터라고 표현하지 않는다.
작품별 reference cohort를 사용할 수 있는 기존 정규화 조건을 유지한다.

## 5. 예측기 학습과 조정

- 측정치별·조건별 **작은 선형 ridge 예측기**를 별도로 학습한다. 비선형 MLP를 추가하지 않는다.
- 절편은 규제하지 않는다. 각 작품군에 같은 총 비중, 작품군 안의 작품에 같은 비중,
  작품 안의 연주에 같은 비중을 준다. 학습 weight의 합은 1이다.
- 학습 입력의 평균·SD도 같은 weight로 계산한다. 비상수 열만 사용하고 target과 test를 보고 고르지 않는다.
- 규제 강도 후보는 `1e-4, 1e-3, 1e-2, 0.1, 1, 10, 100, 1000`으로 고정한다.
- **train 작품군 5-fold CV**만으로 강도를 선택한다. 동률은 더 큰 강도, 즉 더 강한 규제를 선택한다.
- fold는 seed 20261013으로 고정했다. 같은 작품/작품군의 연주는 다른 fold로 나뉘지 않는다.
- 최선 강도로 eligible train 전체에 다시 fit하고 validation/test에 예측한다.
  validation은 결과의 안정성을 함께 보는 용도이며 정답·모델·규제 강도 변경에 사용하지 않는다.
- 모든 조건의 예측값은 주 평가에서 clipping하지 않는다. 동일한 방법으로 오차를 계산한다.

이는 고정 표현에서 측정치를 읽어내는 검사다. 예측기 조정 능력을 통제하기 위해
동일한 절차와 아래 대조군을 함께 사용한다. 이 평가 방식의 일반적인 근거는
[표현 평가와 대조 과제 연구](https://aclanthology.org/D19-1275/)를 참고할 수 있다.

## 6. 발표의 핵심 지표 두 가지

### 전체 측정치 예측 오차

각 연주의 제곱 오차를 작품 안에서 평균하고, 작품군 안에서 작품 평균을 취한 뒤,
작품군 전체를 같은 비중으로 평균한다. test는 현재 작품당 하나의 작품군이다.

`오차 감소율 = 100 × (1 − 보강 조건 MSE / 기준 조건 MSE)`

예를 들어 C의 MSE가 B보다 20% 작으면 개별 시간 보강의 오차 감소율은 20%다.
이는 **성공한 연주 비율이나 50% 무작위 기준을 갖는 정확도가 아니다.**
기준 오차가 `<=1e-12`이면 감소율은 정의하지 않고 오차 자체만 보고한다.

### 같은 작품 안의 연주 차이에 대한 오차

평가 작품별로 실제 측정값에서 그 작품 실제값 평균을 빼고,
예측값에서는 그 작품 예측값 평균을 별도로 뺀 후 같은 방식의 제곱 오차를 계산한다.

메타데이터가 같은 연주에 똑같은 값을 출력하면 예측의 작품 내 편차는 0이다.
추가 임베딩이 어느 연주가 자기 작품의 평균보다 크거나 작은지도 읽어내는지 확인한다.
작품 전체 평균만 맞힌 효과와 연주별 차이를 설명한 효과를 구분하는 지표다.

작품 평균 제거는 **평가 지표 계산에만** 사용한다. 실제 test 측정값 평균을 모델 입력·표준화·학습에 넣지 않는다.
전체 오차만 좋아지고 작품 내부 오차가 좋아지지 않으면,
이번 실험에서 연주별 추가 정보를 확인했다고 결론 내리지 않는다.

## 7. 차원·연주 대응의 대조군

**연주 대응을 섞은 대조:** 같은 작품+grid 안에서 추가 블록만 연주 간 섞는다.
C는 T만, D는 R만 섞고 앞선 입력 블록은 그대로 둔다.
train/validation/test 각각 안에서 따로 섞으며 split·작품을 넘겨 옮기지 않는다.
같은 작품의 메타데이터와 작품 수준의 feature 분포를 유지하면서 연주별 대응만 끊는 검사다.

**같은 차원의 잡음 대조:** C에 해당하는 57D, D에 해당하는 119D를
정답과 무관한 Gaussian 값으로 만들고 같은 전체 학습·조정 절차를 적용한다.
단순히 입력 숫자가 늘어나 예측기가 유리해진 효과를 점검한다.

각 대조는 seed 20261101~20261120의 **20회**로 고정한다. 대조에서도 같은 train-only CV를 수행한다.
실제 보강의 오차 감소와 대조들의 범위를 같이 그린다. 좋은 대조 seed나 좋은 인코더 seed만 고르지 않는다.
CNN/BiLSTM의 세 seed 범위는 인코더 변동이며 20개 대조 범위나 신뢰구간과 구별한다.

## 8. 판단 기준과 불확실성

주 비교는 Y1의 C−B, Y2의 D−C다. 주 비교의 전체 오차와 작품 내부 오차가 함께 줄어야
해당 지식이 평가 작품의 연주별 측정치에 추가 정보를 제공한다는 방향의 근거로 본다.

- 작품군별 오차·개선/악화 개수를 모두 보고한다. 일부 작품의 큰 개선만으로 평균이 바뀌었는지 확인한다.
- 같은 평가 작품군을 짝지어 bootstrap 2,000회(seed 20261016) 재표집해
  오차 차이와 감소율의 percentile 95% 구간을 계산한다. 예측기를 재학습하지 않는다.
- 작품군이 5개 미만이면 구간을 제시하지 않고 작품별 결과만 보고한다.
  현재 주 평가의 test 작품군은 6개/5개이므로 구간과 전체 작품 결과를 함께 제시한다.
- 개선 구간이 0을 포함하거나 실제 보강이 섞기·잡음 대조와 겹치면 안정적인 추가 기여로 확정하지 않고
  **기술적인 개선 또는 미확인 결과**로 분류한다. 작은 평가 작품 수를 함께 표시한다.
- Y3나 E에서만 좋은 결과가 나면 그 결과로 주 가설의 성공을 대체하지 않는다.
- 두 주 측정치의 결과를 각각 보고하며, 가장 좋은 하나만 골라 모든 음악 정보의 개선으로 확대하지 않는다.

긍정 결과의 발표 문장은 다음 범위다.

> 정의한 메타데이터 축과 기존 평균·범위에 비해, 시간/공동 변화 지식을 보강한 표현에서
> 평가 작품의 연주별 측정치를 더 정확하게 읽어낼 수 있었다.

이는 **선형 예측기로 읽을 수 있는 추가 정보**의 근거다.
현재 cosine 거리나 추천 순위가 그 정보를 같은 정도로 사용한다는 결론은 이 예측 과제로 대신하지 않는다.
음악적 지식의 모든 측면에 대한 보존이나 모든 종류의 메타데이터에 대한 독립성을 주장하지 않는다.

## 9. 발표 figure와 저장할 결과

1. **측정치 설명:** 같은 작품의 고정 연주 예시에서 원래 곡선→32/64-beat 구간 통계→전곡 측정치를 표시한다.
   작품 이름순/중앙 연주 등 성능과 무관한 기준으로 고르고 제외 상태도 기록한다.
2. **추가 설명력:** A0/A1/B/C/D/E의 전체·작품 내부 오차를 나란히 표시한다.
   전체 MSE를 A1 대비로 표시하고 B→C, C→D 주 비교의 감소율을 별도로 강조한다.
3. **대조·안정성:** 실제 보강과 20회 섞기/잡음 대조의 개선 범위, 작품별 개선/악화, 신경망 3 seed를 표시한다.

실행 시 `predictions.csv`, `metrics.csv`, `per_work_metrics.csv`, `cv_results.csv`,
`controls.csv`, `bootstrap.csv`, `verification.json`을 저장한다.
각 예측 행에는 recording key·work/family·role·target·condition·encoder seed·정답·예측값을 포함한다.
설계 당시의 protocol·schema·표본 manifest hash도 실행 결과에 저장한다.
