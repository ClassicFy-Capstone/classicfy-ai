# 구간 반응 요약과 전곡 평균의 중복 진단

2026-10-14 KST. 기존 `standalone_structure`의 동일 335연주, 247개 후보,
test 45연주와 validation 43연주를 사용한 사후 탐색 분석이다.
기존 경계·긴장도·입력·검색/평가 분할은 변경하지 않았다.
원래 실험 파일과 저장소 소스는 수정하지 않았다.

## 확인된 결과

**구간별 평균 수준은 전곡 평균과 강하게 겹친다. 그러나 66/198차원 반응 전체가
전곡 평균·범위와 동일한 정보를 담는다고 결론 낼 수는 없다.**

| 표현 | 구간 평균 / 전곡 평균 Pearson 중앙값 | 같은 작품 내 편차끼리의 Pearson 중앙값 | 평균 좌표 분산 중 세 bin의 공통 성분 |
|---|---:|---:|---:|
| F: 고정 구간 | 0.968 | 0.969 | 87.9% |
| P: 프레이즈 | 0.959 | 0.960 | 85.2% |
| H: 긴장도 | 0.946 | 0.948 | 82.1% |

상관은 7개 지표 각각에서 각 context 평균과 동일 연주·검색 view의 signed 전곡 평균을
비교한다. 작품군→작품/grid→연주 균등 가중으로 계산하고, context·channel·두 방향의
상관계수 중앙값을 표시했다. 같은 작품 내 비교는 각 좌표의 작품별 평균을 먼저 제거했다.
Rubato의 상관은 P 약 0.790, H 약 0.750으로 다른 지표보다 낮다.

공통 성분 비율은 **평균 좌표에만** 해당한다. 각 지표의 세 bin에 공통적인 값과
bin 사이 차이로 연주 간 분산을 직교 분해한 것이다. H는 긴장 지표별로 세 bin을 분해한다.
전곡 평균과의 동일성 비율이나 전체 반응 66/198차원의 정보 중복 비율은 아니다.
채널 크기는 gallery의 signed 전곡 평균 표준편차로 맞췄다.

기존 B는 7개 평균/범위 14D이며, Rubato의 수준 좌표만 signed 평균 대신 절댓값 중앙값이다.
따라서 위 상관의 전곡 signed 평균과 기존 B를 동일시하지 않는다.

## 전체 검색 표현도 비슷한가?

| 표현 | B와 후보 거리 순서의 Spearman: test / validation | B와 같은 Top 5 연주 비율: test / validation |
|---|---:|---:|
| P 전체 | 0.416 / 0.402 | 13.2% / 6.6% |
| H 전체 | 0.442 / 0.405 | 12.0% / 8.9% |
| P+H 전체 | 0.463 / 0.437 | 17.4% / 8.2% |

거리 순서의 상관은 query마다 동일 247개 후보에 대해 구한 뒤 작품별·작품군별로 평균했다.
Top 5는 기존과 같이 작품군당 최대 한 연주를 선택한다.
구간 평균끼리의 높은 상관이 곧 전체 검색 순위의 동일성을 뜻하지는 않는다.

## 평균 좌표를 제거하면?

모든 bin의 22개 좌표 중 7개 평균 좌표를 제외했다. 나머지 15개는
인접 변화 평균 7개, 변화 RMS 7개, Tempo–Dynamics 공동 변화 모멘트 1개다.
이들을 유지한 `change_only`를 비교했다. P/F는 45D, H는 135D가 된다.
변화 좌표에도 전체 변화 규모 정보가 남으므로 모든 범위 정보까지 제거한 것은 아니다.

| 검색 표현 | 전체 E-S: test / validation | 평균 좌표 제거 E-S: test / validation |
|---|---:|---:|
| P | 54.09 / 55.52 | 54.39 / 56.11 |
| H | 53.68 / 52.83 | 50.67 / 50.38 |
| P+H | 54.57 / 55.66 | 56.70 / 56.51 |

이는 기존 프레이즈 평가 E-S이며 긴장 episode 평가가 아니다.
기존 gallery-only SD, 다른 train 작품군 거리 중앙값 보정, P/H 동일 가중 결합을 유지한다.
E-L/E-T/E-R 및 같은 작품에서 연주를 다시 뽑는 기대값도 `summary.csv`에 기록했다.

**P+H의 주 표 점수 상승은 추가 대조에서 일관되게 유지되지 않는다.**
작품/grid마다 세 연주로 후보 수를 맞춘 기존 20 seed를 그대로 적용하면:

| 표현 | 전체 E-S: test / validation | 평균 좌표 제거 E-S: test / validation |
|---|---:|---:|
| P | 54.11 / 54.46 | 53.04 / 54.63 |
| H | 50.40 / 52.83 | 51.14 / 52.48 |
| P+H | 53.28 / 54.80 | 53.41 / 54.55 |

주 표 P+H change_only의 실제 56.70 / 56.51과 같은 반환 작품 내 무작위 연주 기대값
57.35 / 55.96도 함께 본다. 두 split에서 특정 연주 선택의 추가 효과를 확정할 수 없다.

## 추가 분리 조건과 해석

- `means_only`: bin별 평균 7개만 유지한다.
- `mean_centered`: bin별 평균에서 동일 연주·동일 검색 view의 signed 전곡 평균을 빼고,
  변화 좌표는 유지한다. 전체 데이터나 평가 view의 평균을 빼지 않는다.
- `change_only`: bin별 평균 좌표를 모두 제외한다.

모든 조건의 숫자와 검색 중복은 `summary.csv`, query별 값은 `queries.csv`에 있다.
이는 사전 등록한 성공 판정 실험이 아니라, 이전 결과를 보고 추가한 원인 진단이다.
test/validation은 각각 세 작품군에 불과하다. 새 음악적 정답, 긴장 평가, 복잡한 모델은 추가하지 않았다.

현재 근거는 평균 성분 중복을 먼저 분리해 볼 필요가 있다는 것이다.
중복만으로 기존 결과의 원인을 확정하거나, 평균 제거를 새 최적 표현으로 선택하지 않는다.
구조 자체의 타당성 및 시간 순서를 요약으로 잃는 문제는 별도로 남는다.

## 재현 및 검산

저장소 루트에서 실행:

```bash
.venv/bin/python ../diagnostics/summary_mean_overlap/analyze.py
```

외부 저장 배열 `datasets/standalone_structure_run01/standalone.npz`가 필요하다.
스크립트는 이 진단 폴더의 출력 CSV/JSON만 덮어쓴다.
기존 모든 B 기반 및 단독 검색 거리 배열을 재현했다. 최대 오차는 0이다.
기존 B/F/P/H/P+H의 네 평가 축 전체 점수를 재현했고, 최대 오차는 약 1.42e-14점이다.
공통 분산과 context 대비 분산의 합이 전체 평균 좌표 분산과 일치하는지도 검사했다.
입력 SHA 및 정의·제한은 `verification.json`에 있다.
