# 평가 기준과 비교 대상의 역할 정리

2026-10-14, 마지막 사용자 논의 반영. **고정된 프레이즈·긴장 반응 score를 평가 기준으로 두고, 기존 전체 흐름 기반 모델의 유사도가 그 기준을 얼마나 반영하는지 먼저 확인한다.** 이후 같은 기준으로 새 구간 모델의 추가 이득을 비교한다. 이 head-to-head 비교는 아직 실행하지 않았다.

## 핵심 질문

연구의 출발점은 전체 연주 흐름의 비슷함을 연주 간 유사도로 표현하는 것이었다. 후속 가설은 프레이즈·긴장 구간의 반응 유사성이 우리가 중요하게 보는 연주 유사성을 더 잘 나타낼 수 있다는 것이다.

따라서 두 역할을 구분한다.

- **평가 기준:** 관측 연주에서 별도로 계산하고 고정한 프레이즈 반응 score와 긴장 반응 score.
- **평가 대상:** 기존 전체 흐름 기반 표현의 거리/유사도/검색 순위. 이어서 새 구간 표현과 둘의 결합을 동일 조건에서 비교한다.

전체 흐름 모델에서 비슷하다고 판단한 쌍이 구간 score에서도 비슷한가, 가장 가까운 후보의 score가 무작위보다 높은가, 전체 흐름은 비슷하지만 구간 반응은 다른 쌍을 구별하는가를 확인한다.

## 이번 실험에서 확인한 것과 빠진 비교

반대 view의 고정 구간 score로 구간 모델의 검색을 평가한 부분은 이 질문에 사용할 수 있다. 하지만 비교 대상은 구간 요약/곡선과 이전·새 구간 모델이었다. 기존64-beat CNN/BiLSTM/Transformer 전체 연주 표현을 동일329개 cohort·후보·분리 view·구간 score에 넣은 직접 비교는 없었다.

특히 마지막 .573→.781/.537→.748은 학습한 관측 구간 거리 목표를 새로운 작품의 입력에서도 벡터가 얼마나 표현하는지에 관한 진단이다. 이것을 전체 흐름 baseline 대비 연주 유사성 검색 개선으로 해석하지 않는다.

기존 전체 연주 표현도 전곡을 한 번에 읽는 방식은 아니었다.64-beat 구간을 시계열 encoder로 읽고 구간 벡터의 평균/표준편차로 전곡 표현을 만들었다. 새로운17점 구간 표현과는 입력 길이, 시간 해상도, level 처리, pooling, 목표가 다르다. 이 차이를 숨겨서 단순한 모델 크기 비교로 취급하지 않는다.

## 다음 비교에서 고정할 항목

1. 같은 연주 cohort·query·후보를 고정하고 같은 작품 내 비교와 다른 작품 비교를 분리한다.
2. 프레이즈 score와 긴장 score를 먼저 별도로 본다. 결합 score를 쓰려면 목적과 가중치를 결과 관찰 전에 정한다.
3. score는 비교 모델의 embedding으로 만들지 않는다. 관측 반응의 모양·크기·시차 중 무엇을 중요하게 볼지 정의하고 유효성/결측/구간 대응을 유지한다.
4. 기존 checkpoint의 데이터/작품군 split, 평가 view 사용 여부와 scale reference를 먼저 감사한다. 현재 평가 연주가 학습에 들어간 모델을 새로운 일반화 증거로 사용하지 않는다. 필요하면 같은 split/관측 조건으로 baseline을 재학습한다.
5. 거리의 방향을 맞춘다. 기존 거리와 높은 score는 반대 방향이며, 유사도(`-distance` 등)와 높은 score는 같은 방향이다.
6. 전체 시계열 표현, 구간 반응 표현, 둘의 고정 결합을 같은 후보·TopK·평가식으로 비교한다. 가장 좋은 test seed/가중치를 사후 선택하지 않는다.

같은 작품에서는 검증된 악보 위치·반복 방문으로 대응하는 구간을 비교한다. 다른 작품에서는 같은 마디 번호를 직접 맞대지 않고 비교할 음악적 맥락 또는 반응 분포의 정의를 별도로 고정해야 한다.

## 판단 지표와 해석

| 검사 | 답하려는 질문 |
|---|---|
| 쌍별 유사도와 구간 score의 순위 상관 | 기존 표현이 구간 score의 가까움/멀어짐을 얼마나 반영하는가 |
| 같은 후보의 TopK 구간 score | 실제로 선택한 후보의 반응이 평가 기준에서도 비슷한가 |
| 구간 score가 높은 후보를 찾는 순위/검색 효율 | 전체 흐름 표현이 원하는 구간 기준의 후보를 놓치는가 |
| 작품 고정 무작위 연주 교체 | 작품 선택과 특정 연주 선택 중 무엇이 점수를 설명하는가 |
| 후보 수·순서 섞기·작품군별 결과 | 후보 규모/시간 순서/일부 작품에만 의존하는가 |

기존 표현이 score를 잘 반영하면 새로운 구조 모델의 필요성이 아직 입증되지 않는다. 기존 표현이 잘 반영하지 못하고 새 구간 표현이 같은 조건에서 더 잘 반영하면 추가 설계의 근거가 된다. 두 표현을 결합했을 때도 고정 기준에서 추가 이득이 있는지 확인한다.

구간 score는 이번 연구에서 제안하는 기준이며 곧바로 청취 정답은 아니다. 기존 모델과의 불일치는 우선 서로 다른 유사성 개념을 표현한다는 증거다. 사람의 취향/음악적 유사성에 관한 성능 주장에는 score 정의의 검증 또는 독립적인 청취 근거가 필요하다. 또한 이미 관찰한 test는 개발 benchmark로 표시하고 새로운 최종 검증을 마련한다.

## 미완료 항목

- 기존 전체 흐름 checkpoint의 현재 분할·관측 조건 적합성 감사.
- 평가용 구간 score의 최종 정의와 중요도 고정.
- 동일 조건의 전체 흐름/구간 반응/고정 결합 비교.
- 수치 기준의 음악적·청취 유효성 검증.

이번 커밋은 위 작업을 이미 수행한 것처럼 기록하지 않는다. 현재 저장된 수치는 이전 실험의 완료 결과이며 다음 비교의 설계 근거로 사용한다.
