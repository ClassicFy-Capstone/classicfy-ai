# ATEPP_refine 시대별 100개 작품·악장 표본

2026-11-06 사용자 지시에 따라 **현재 `datasets/ATEPP_refine`에 실제 포함된 연주만**
대상으로 고전·바로크 / 낭만 / 인상주의·현대 각 100개 작품·악장을 선정했다.
최종 표본은 300개 composition_id, 1,864개 녹음이다.

| 시대 | refine 전체 작품·악장 | refine 전체 녹음 | 선정 작품·악장 | 포함 녹음 | 선정 작곡가 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 고전·바로크 | 621 | 5,237 | 100 | 761 | 6 |
| 낭만 | 691 | 4,556 | 100 | 676 | 12 |

## 선정 기준

- 원본의 `composition_id`를 작품 단위로 사용한다. 개별 악장/모음곡의 개별 곡도 포함하므로
  300개가 모두 여러 악장을 합친 전곡 작품이라는 뜻은 아니다.
- 시대별 100자리를 해당 시대의 **작곡가별 작품 수에 비례하여 배분**한다. 모든 작곡가를
  포함하도록 최소 1자리를 보장하고, 정수화 후 남는 자리는 할당 부족분 순으로 배정한다.
- 작곡가 안에서는 seed `20261106`과 시대·작곡가·composition_id의 SHA256 순서로
  중복 없이 추출한다. 이 방식으로 입력이 같으면 같은 목록을 재생성할 수 있다.
- 선택된 작품에 속하는 **refine 내 모든 녹음**을 유지한다. 원본에서 이미 제외된 연주를
  다시 넣지 않는다. 녹음 수까지 시대별로 같게 맞추거나 추가 중복 제거를 하지 않았다.
- 악보 보유·품질 라벨·정렬 성공·feature 보유·feature 값·최소 녹음 수로 추가 선별하지 않았다.
- 작품 제목 표기가 녹음마다 다를 수 있어 가장 빈번한 제목을 대표값으로 사용했다.
  원본의 각 녹음 제목은 `selected_recordings.csv`에 그대로 보존한다.

시대는 직전 전체 집계와 같은 작곡가 단위 분류다. 베토벤은 고전·바로크,
라흐마니노프와 스크랴빈은 낭만에 포함하고 경계 작곡가 표시를 남겼다.
작품별 작곡 연도/양식을 검증한 분류는 아니다. 전체 작곡가별 할당과 녹음 수는
[composer_summary.csv](composer_summary.csv)에서 확인할 수 있다.

refine에는 앞서 적용된 전체 연주 길이 60초 이상, 모든 representative 주제부 후보 길이
10~60초 조건이 유지되어 있다. 원본 11,674개 중 975개를 제외한 10,699개가 모집단이다.
기존 필터는 다시 변경하지 않았으며, 원본과 refine의 파일을 복사·이동·수정하지 않았다.

## 후속 feature 관찰과 구분

후속 tempo 추출과 시대 라벨 figure는 [작품별 tempo 분석](../era_refine_tempo/README.md)에 있다.
300개 선정작품 중 절대값 46개·상대 분포 폭 42개가 산출되었고, 나머지는 사유와 함께 미산출로 보존했다.

이 폴더의 선정 단계에서는 작품 그룹과 녹음 목록을 확정했고, feature 추출은 위 후속 분석에서 수행했다.
시대별 작품 수는 같지만 녹음 수와 작곡가별
작품 수는 다르므로 후속 관찰은 작품별 요약을 먼저 계산한다.

선정 작품 중 악보가 연결된 작품은 고전·바로크 32개, 낭만 9개, 인상주의·현대 17개다.
이는 악보 파일 제공 여부이며 정렬/feature 산출 성공을 뜻하지 않는다. 모든 300개에서
다섯 feature를 완전하게 얻을 수 있다고 가정하지 않고, 산출 가능 여부를 별도로 기록해야 한다.
최소 녹음 수 제한도 없으므로 같은 작품 내 연주 차이를 관찰할 수 있는 범위는 별도로 구분한다.

## 재현과 검증

저장소 루트에서 Python 표준 라이브러리만으로 실행한다. 기본 입력은 ATEPP_refine이고,
`--out`으로 다른 출력 폴더를 지정할 수 있다.

```bash
python3 classicfy-ai/scripts/prepare_balanced_era_cohort.py
```

[protocol.json](protocol.json)에 모집단, 분류, seed, 할당 규칙, 입력 파일/스크립트 SHA256을
저장했다. [verification.json](verification.json)에 다음 독립 검증 결과가 있다.

- 원본 메타데이터와 모든 주제부 후보 길이에서 refine 제외 975개를 재구성해 현재 멤버십과 대조.
- 시대별 100개, composition_id 고유 300개, perf_id 고유 1,864개 및 25명 작곡가 포함 확인.
- 선택된 작품의 refine 녹음 전체가 누락 없이 포함되고 원래 메타데이터 필드가 보존됨을 확인.
- 선택 MIDI 1,864개 모두 refine 폴더에서 읽어 기록된 SHA256과 대조; 제외 녹음 유입 0개.
- SQL로 시대별 집계 독립 확인, 추출 순위/할당 확인, 별도 출력 폴더 재생성 9개 파일 byte 일치.

이 표본이 현재 기준이다. 앞서 생성한 원본 전체 300개 후보와 과거 161그룹 부분집합은
이 refine 표본의 입력이나 최종 목록으로 사용하지 않는다.
