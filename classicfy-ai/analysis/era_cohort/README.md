# 시대별 다섯 feature 관찰을 위한 첫 표본

**철회된 표본 정의:** 아래는 기존 분석의 161개 부분집합이며 ATEPP 전체를 대표하는
시대별 표본으로 확정한 판단은 대화에서 철회했다. 현재 사용자가 지정한 입력과 표본은
[ATEPP_refine 시대별 100개](../era_refine_balanced_100/README.md)다. 아래 기록은 이력으로 보존한다.

2026-11-06에 기존 ATEPP-1.2 연주 다양성 분석의 적격 표본을 기준으로 확정했다.
feature 값이 원하는 방향으로 나타나는지를 보고 작품을 선택하지 않았다.

| 시대 | 작곡가 수 | 작품·악장/악보 그룹 수 | 녹음 수 |
| --- | ---: | ---: | ---: |
| 고음악 | 1 | 8 | 58 |
| 고전·낭만 | 7 | 128 | 2,156 |
| 근현대 | 2 | 25 | 274 |
| 합계 | 10 | 161 | 2,488 |

여기서 그룹은 기존 `piece + grid` 단위다. 소나타의 개별 악장이나 모음곡의 개별 곡이
한 그룹일 수 있으므로, 161개가 모두 독립적인 전곡 작품이라는 뜻은 아니다.
같은 상위 작품의 악장을 연결하는 작업은 이번에 수행하지 않았다.
녹음 수는 서로 다른 연주자 수와도 다르다. 같은 연주자의 여러 녹음은 유지했다.

## 분류와 작곡가 구성

| 시대 | 작곡가 | 세부 분류 | 그룹 수 | 녹음 수 |
| --- | --- | --- | ---: | ---: |
| 고음악 | 바흐 | 바로크 | 8 | 58 |
| 고전·낭만 | 하이든 | 고전 | 2 | 11 |
| 고전·낭만 | 모차르트 | 고전 | 26 | 287 |
| 고전·낭만 | 베토벤 | 고전·낭만 전환 | 71 | 1,579 |
| 고전·낭만 | 슈베르트 | 낭만 | 9 | 90 |
| 고전·낭만 | 슈만 | 낭만 | 5 | 68 |
| 고전·낭만 | 리스트 | 낭만 | 11 | 85 |
| 고전·낭만 | 라흐마니노프 | 후기 낭만 | 4 | 36 |
| 근현대 | 드뷔시 | 프랑스 세기 전환기 음악 | 16 | 163 |
| 근현대 | 라벨 | 프랑스 세기 전환기 음악 | 9 | 111 |

이 라벨은 **작곡가의 대표 양식을 사용하는 탐색용 분류**다. 작품별 작곡 연도와
양식을 개별 검증한 음악사 정답 라벨은 아니다. 따라서 모든 행에
`classification_basis=composer_style_proxy`, `composition_date_verified=False`를 기록했다.

베토벤은 두 시대를 묶은 고전·낭만에 포함하고 전환기 표시를 남긴다.
라흐마니노프는 달력상의 20세기 여부와 별개로 후기 낭만 양식을 기준으로
고전·낭만에 포함한다. 이 선택의 근거로 [Boosey & Hawkes의 작곡가 소개](https://www.boosey.com/composer/sergei+rachmaninoff)는
그의 낭만적 화성을 설명한다. 해당 자료는 분류 판단을 돕는 근거이며, 표본의
네 작품을 각각 음악학적으로 검증한 결과는 아니다.
드뷔시·라벨의 모든 작품을 같은 세부 양식이라고 단정하지 않도록 세부 라벨은 넓게 유지했다.

## 포함·제외 기준

1. 기존 [연주 다양성 분석](../atepp_style_diversity/README.md)의 적격 161개 그룹을 모두 사용한다.
2. 원래 표본은 그룹당 5개 이상 녹음, 7개 채널 모두에서 32개 이상 공통 유효 위치,
   공통 coverage 50% 이상을 만족한다. 다섯 feature 중 Pedaling은 세 채널이다.
3. MIDI SHA256이 동일한 중복은 녹음 key의 사전순 첫 항목만 유지한다.
4. 동일 MIDI인 `07314`와 `07328` 중 `07314`를 남기고 `07328`을 제외했다.
   베토벤 Op.57 2악장 그룹이 64개에서 63개 녹음으로 줄었고, 그룹 탈락은 없다.
5. 희소 시대에 맞추어 다른 시대의 표본을 버리거나, 예상 feature 특징에 맞는 작품만
   선택하지 않는다. 작곡가가 없거나 소수인 시대는 그 한계를 함께 보고한다.

공통 유효 위치와 coverage는 **기존 전체 표본에서 확인한 값**이다. 이번에는 원본 MIDI와
대용량 feature 캐시를 다시 읽거나 결측률을 재산출하지 않았다. `works.csv`에 원래
멤버십과 유지 멤버십을 모두 저장했다. 후속 비교는 원래 표본의 공통 위치를 기준으로
원래 단위의 값도 확보해야 하며, 기존 정규화 값을 시대의 절대 표현 크기로 해석하지 않는다.
중복 제거를 이유로 이번에 reference나 scale을 다시 fit하지 않았다.

## 집계와 경계 표본 비교

주 분석은 시대 안에서 각 작품·악장/악보 그룹의 총 가중치를 같게 한다.
그룹 안 녹음은 그 가중치를 나누어 갖는다. 그룹별 요약을 먼저 구하고 시대별 분포를
관찰하면 베토벤의 녹음 수가 많다는 이유로 개별 녹음 집계가 지배되는 것을 줄일 수 있다.
작곡가별 작품 수 차이는 여전히 남으므로 작곡가별 결과와 작곡가 균등 집계도 보조 보고한다.

| 표본 | 고음악 그룹/녹음 | 고전·낭만 그룹/녹음 | 근현대 그룹/녹음 |
| --- | ---: | ---: | ---: |
| 주 표본 | 8 / 58 | 128 / 2,156 | 25 / 274 |
| 베토벤 제외 | 8 / 58 | 57 / 577 | 25 / 274 |
| 라흐마니노프 제외 | 8 / 58 | 124 / 2,120 | 25 / 274 |
| 두 경계 작곡가 모두 제외 | 8 / 58 | 53 / 541 | 25 / 274 |

이는 표본 정의이며, 경계 표본에서 feature 결과가 유지되는지는 아직 분석하지 않았다.
고음악은 바흐만, 근현대는 드뷔시·라벨만 포함한다. 중세·르네상스·현대음악 전체에 대한
결론을 낼 수 없고, 시대 효과와 작곡가 효과를 완전히 분리할 수도 없다.

## 파일과 재현

- [작품·악장/악보 그룹 전체 목록](works.csv): 제목, 작곡가, 시대, 녹음 수, 공통 coverage, 원래/유지 key 목록.
- [녹음 전체 목록](performances.csv): 유지한 2,488개 key, MIDI SHA256, 연주자, 시대와 경계 표본 포함 여부.
- [제외한 녹음](excluded_performances.csv): 중복 key, 제외 사유, 대신 유지한 key.
- [시대별 집계](era_summary.csv), [작곡가별 집계](composer_summary.csv), [경계 표본별 집계](sensitivity_cohorts.csv).
- [생성 조건과 입력 해시](protocol.json), [독립 목록 검증](verification.json).

저장소 루트에서 Python 표준 라이브러리만으로 재생성한다.

```bash
python3 classicfy-ai/scripts/prepare_era_cohort.py
```

`--out`으로 다른 출력 폴더를 지정할 수 있다. 입력의 기존 해시는 줄바꿈 LF/CRLF만
다른 경우를 명시적으로 허용한다. 실제 로컬 해시와 기존 기록과의 대응 방식을
`protocol.json`에 모두 보존한다. 원본 CSV의 줄바꿈과 데이터는 수정하지 않는다.
독립 검증은 생성 스크립트를 다시 호출해 검증 파일을 생성하는 방식과 별개로 수행했다.
이 표본 결정에서 feature 비교·시각화·학습·청취 평가는 실행하지 않았다.
