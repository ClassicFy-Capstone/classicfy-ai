# 진행 결과와 구조에 따른 연주 반응의 후속 비교

이 문서는 현재 검색 실험의 결과와 다음 연구 방향을 정리한다.
**프레이즈·조성 긴장도 추출과 후속 비교는 아직 구현하거나 실행하지 않았다.**
기존 [실험 설계](../metadata_retrieval_design/README.md)와 protocol은 변경하지 않는다.

## 현재 확인한 내용

- 평균·범위 검색은 작곡가+유형 추천과 작품군이 약 24.3% 겹쳤다.
  메타데이터 동점만 다르게 해소한 목록끼리는 약 73.3% 겹쳤다.
- 검색에 쓰지 않은 구간의 성향·폭 점수는 평균·범위 69.1점, 작곡가+유형 50.6점이었다.
  반환 작품을 유지하고 연주만 무작위로 고르면 52.2점이었다.
- 시간 정보 추가는 주 국소 변화 점수가 test에서 2.1점 높았지만 validation과 후보 수 균형 대조에서는 유지되지 않았다.
- 관계 정보 추가는 주 공동 변화 점수를 평균적으로 개선하지 못했다.
- 구간 평가 test가 4작품군이므로 확증 신뢰구간을 보고하지 않았다.
  현재 표본의 탐색적 근거이며, 모든 작품·청취 유사성으로 확대하지 않는다.
- 구현·CSV 집계·그림 6종·원래 #14 코드 및 별도 정렬을 이용한 독립 재계산을 완료했다.
  신규 단위 테스트 8개와 독립 검증을 통과했다. 상세 수치는 [결과 보고서](README.md)에 있다.

## 다음 질문

**같은 연주 feature라도 곡 전체의 시간 통계로 비교할 때보다,
프레이즈·조성 긴장도에 따른 구간별 반응으로 비교할 때 스타일 검색이 더 좋아지는가?**

예를 들어 ‘변화가 얼마나 큰가’에 더해 ‘프레이즈 종결에서 어떻게 변화하는가’,
‘긴장도가 올라가거나 풀리는 상황에서 빠르기·강약이 어떻게 함께 움직이는가’를 표현한다.
현재 결과는 이 방향을 검토하는 동기다. 구조 정보의 부족이 기존 보강 실패의 원인이라고 확정하지 않는다.

## 필요한 구조 정보

- ASAP에는 악보 MIDI와 MusicXML, beat/downbeat·조표 주석이 있다.
  프레이즈·긴장도의 완성된 정답 라벨은 별도로 제공되지 않는다.
- 로컬의 기존 55작품/악보 변형 모두 MusicXML이 있고, 41개에서 슬러 표기를 확인했다.
  슬러를 그대로 프레이즈 경계로 확정하지 않고 쉼·선율·종지 등의 단서와 함께 검수한다.
- 긴장도는 악보 음높이·악보상 길이·조성 정보로 cloud diameter, cloud momentum, tensile strain을 계산한다.
  연주의 velocity·실제 타이밍을 긴장도 입력에 섞지 않는다. 조표만으로 장단조/국소 조성을 확정하지 않는다.
- 작품당 구조를 만들고, 반복 구간과 악보–연주 대응을 확인해 각 연주의 기존 beat index에 연결한다.
  경계·조성 추정의 불확실성과 지원 수를 저장한다.

자료: [ASAP 공식 설명](https://github.com/fosfrancesco/asap-dataset#dataset-content),
[Partitura 긴장도 계산](https://partitura.readthedocs.io/en/latest/modules/partitura.musicanalysis.html#partitura.musicanalysis.estimate_tonaltension).

## 비교 조건 초안

| 조건 | 비교 목적 |
|---|---|
| 평균·범위 B | 현재 전반적인 성향·폭 기준 |
| B + 전곡 시간·관계 요약 | 구조를 쓰지 않는 주 대조 |
| B + 고정 길이 구간의 시간·관계 요약 | 구간화 자체의 효과를 분리 |
| B + 프레이즈에 따른 반응 | 시작·중간·종결 등에서의 표현 차이 |
| B + 긴장도에 따른 반응 | 긴장 수준·증가·감소에 대한 표현 차이 |
| B + 프레이즈·긴장도에 따른 반응 | 두 맥락의 결합 효과 |

구간화만 해도 좋아질 수 있으므로, 고정 길이 구간 기준을 함께 비교한다.
반응 표현의 차원 수·pooling·학습 용량을 가능한 한 맞추고 다르면 명시한다.
악보 구조 자체만 사용한 조건, 시간 대응을 섞은 구조 조건도 대조로 둔다.
‘더 많은 좌표/모델 용량’이나 ‘작품 구조를 더 잘 맞힌 효과’와 연주 반응의 효과를 구분한다.

## 평가 원칙

- 같은 query와 같은 다른 작품 gallery에서 Top 5를 검색하며, 작품군당 1연주와 메타데이터 동점 처리를 유지한다.
- 구조 정보를 계산할 수 있는 **공통 cohort에서 기존 전곡 기준도 다시 실행**한다.
  지금 보고한 69.1점과 새로운 부분 표본의 점수를 그대로 빼지 않는다.
- 메타데이터와의 연주/작품군 겹침, 별도 구간 스타일 일치, 같은 작품 연주 대조,
  길이·coverage 및 후보 수 균형 대조를 계속 보고한다.
- 기존 E-L/E-T/E-R는 공통 비교로 유지한다. 구조에 따른 반응이 읽히는지 확인할 추가 평가 축은 실행 전에 정의한다.
  검색 입력의 반응 계수를 그대로 정답으로 복사하지 않는다.
- 표현값은 검색 쪽 구간만으로 계산하고 다른 구간/프레이즈 사례에서 평가한다.
  같은 프레이즈의 전체 표현 곡선을 검색과 평가에 동시에 사용하지 않는다.
- 기존 작품별 공통 제거는 구조에 따른 공통 반응도 일부 제거할 수 있다.
  무엇을 공통 반응으로 보고 어떤 잔차를 개인차로 비교할지 먼저 정의하고 정규화 조건을 맞춘다.
- 시간/관계 점수와 성향·폭 점수를 모두 공개한다. 특정 축의 개선과 다른 축의 손실을 구분한다.
  구조 추출 가능률·평가 작품군 수를 먼저 점검하고 결과에 따라 조건을 완화하거나 좋은 작품만 고르지 않는다.

우선 긴장도 계산과 소수 악보의 프레이즈 검수로 입력 품질을 점검한다.
후속 실험의 세부 구간 정의·모델·주 지표·표본·대조를 고정한 뒤 구현과 검색 평가를 진행한다.
