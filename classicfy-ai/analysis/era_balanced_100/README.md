# 원본 전체 기준 300개 후보 — 대체됨

이 폴더는 원본 ATEPP 1.2 전체 11,674개 연주에서 시대별 100개를 추출하던 중 생성한
이전 후보 자료다. 사용자가 대상을 ATEPP_refine으로 변경했으므로 현재 최종 표본은
[ATEPP_refine 시대별 100개 표본](../era_refine_balanced_100/README.md)이다.

이전 자료를 비교 이력으로 보존했다. 이 폴더의 protocol에 기록된 스크립트 해시는
refine 지원으로 수정하기 전의 코드 버전이다. 현재 기본 실행의 출력 대상도
`era_refine_balanced_100`으로 변경되었다.
