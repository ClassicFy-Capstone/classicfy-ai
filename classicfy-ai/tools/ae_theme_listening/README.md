# 선정 주제부 A/X/Y 청취 — 고전·바로크 4 / 낭만 4 / 인상주의 2

이번 선정 구간 AE의 **14 epoch**로 구성한 10문항이다. 시대 비율은 기준 연주 A에 적용한다.
각 문항은 A와 다른 작품에서 가까운 연주와 먼 연주를 X/Y로 비교한다.

```sh
python3 classicfy-ai/tools/ae_theme_listening/serve.py
```

**http://localhost:8766/** 으로 접속한다. 이미 서버가 실행 중이면 해당 주소를 열거나 새로고침한다.
`127.0.0.1`로 접속하면 기존 응답을 보존하며 localhost로 이동하는 기능이 유지된다.

## 사용

1. A의 선정 주제부를 듣고 X와 Y를 비교한다. 구간 재생은 끝에서 멈추고, 반복 선택 시 같은 구간을 반복한다.
2. X/Y 중 비슷한 쪽 또는 동점·판단 어려움을 고른다. X/Y 순서는 브라우저마다 무작위이며 재방문 시 유지된다.
3. 선택 저장 후 모델의 거리와 실제 후보 연주자가 공개된다. 동점·판단 어려움은 확정 선택 일치율에서 제외한다.
4. 응답·메모·X/Y 순서·시간 수정은 브라우저에 저장되며 JSON으로 내보낼 수 있다.

X/Y의 선정 후보 번호는 같지만 연주별 추정 악보 경계와 음표 수는 다를 수 있다.
영상 시간 오프셋은 청음 검수 전이다. 시작 위치가 어긋나면 ‘재생 문제 확인용 시간 표시’에서 조정한다.
원본 링크도 제공한다. 실제 녹음을 다운로드하거나 재합성하지 않는다.

## 선정 규칙

- 모델: `diagnostics/atepp_selected_style_training/run01/best.pt`, 14 epoch.
- 입력: `datasets/atepp_selected_segment_ae/run02`. 각 연주의 선정 구간 전체를 한 번 인코딩한다.
- 거리: 선정 구간 임베딩의 cosine 거리. 전곡 8마디 표현의 평균을 사용하지 않는다.
- B: A와 다른 작품·악보 후보 전체의 실제 최근접 연주.
- C: B와 같은 작품·악보·반복 경로·선정 후보 번호가 같은 후보 중 **A에서** 가장 먼 다른 원본 녹음.
- 문항 사이 작품·악장 ID와 녹음을 중복하지 않으며, 연주자는 전체 30구간에서 최대 2회 등장한다.
- 한 문항의 세 연주자는 모두 다르다. 구간 길이 15–90초, B/C 거리 차이 최소 0.05.
- 기준 A는 바로크 2(서로 다른 BWV), 고전 2, 낭만 4, 인상주의 2. 고정 난수 순서와 다양성 조건으로 선택한다.
- 삽입 재생 실패 시 해당 문항을 제외하고 다른 A 문항을 선택한다. B/C를 임의로 차순위로 바꾸지 않는다.
- g와의 일치 여부나 사람이 느끼는 유사성으로 문항을 고르지 않았다.

검색 대상에는 train/validation/test 연주가 함께 포함된다. 따라서 청취 응답 일치율은 독립된 test 성능이 아니다.
음색·녹음 환경·작품 차이도 들린다. X/Y 역할 숨김은 UI 기능이며 정적 결과 JSON 접근 통제는 아니다.
